# DevFest Samsun 2026 Assistant

The demo agent from **The Google Cloud Stack for Production AI Agents** (Omar Elcircevi, DevFest Samsun 2026, Saturday Oct 24, 10:30, Kat 1).

A single [ADK](https://google.github.io/adk-docs) agent that answers questions about the real DevFest Samsun 2026 schedule: which talks are on, when, and on which floor. It runs locally with `adk web` and deploys to **Agent Runtime** with the **Agents CLI**.

- **Hands-on lab:** <https://omarcevi.dev/workshops/devfest-samsun-agent>
- **Chat with it on your phone:** <https://omarcevi.dev/demos/devfest-samsun-agent>

## Run the lab in Cloud Shell

```bash
gcloud config set project YOUR_PROJECT_ID
git clone https://github.com/omarcevi/devfest-samsun-assistant.git
cd devfest-samsun-assistant
./lab/setup.sh
uv run adk web --port 8080          # then Web preview › Preview on port 8080
agents-cli deploy --agent-identity  # 5–10 minutes
./lab/cleanup.sh                    # when you're done
```

## What's inside

| Path | What it is |
|---|---|
| `app/agent.py` | The agent: model, instruction, tools, memory |
| `app/tools.py` | `search_sessions`, `get_session`, `submit_feedback`, `get_current_time` |
| `app/memory.py` | Saves each conversation to memory (Memory Bank when deployed) |
| `app/attendees.py` | Optional remote MCP tool, only wired in when `ATTENDEES_MCP_URL` is set |
| `data/agenda.json` | The real schedule, read from [kommunity.com](https://kommunity.com/gdg-samsun/events/devfest-samsun-2026-1057d7ef) |
| `data/attendees.json` | **Entirely fictional** people, used only by the MCP server |
| `mcp/attendees/` | A FastMCP server on Cloud Run that exists to be blocked by policy |
| `evals/` | Eval cases and checks for `agents-cli eval run` |
| `proxy/` | The Cloud Run proxy behind the public chat page |
| `lab/` | `setup.sh` and `cleanup.sh` for the hands-on lab |
| `scripts/` | The speaker's stage demos |
| `docs/` | Runbook, slide snippets, verified commands, screenshots |
| `app/fast_api_app.py`, `app/app_utils/`, `Dockerfile` | Generated by `agents-cli` for Agent Runtime |

## Tags

- `v1-bug`: the agent has no clock, so it recommends talks that already ended.
- `v2-fixed`: adds `get_current_time()` and the `time_awareness` eval case that catches the bug.

`main` is the fixed agent with the real clock.

## Evals

```bash
DEMO_NOW=2026-10-24T14:00:00+03:00 agents-cli eval run \
  --dataset evals/dataset.json --config evals/eval_config.yaml --output artifacts/eval_results
uv run python evals/summary.py
```

`DEMO_NOW` pins the agent's clock so the time-awareness case is reproducible.
